# Skills: sources and credits

The skills in this folder were written for this project. Their text is original; no text was copied from the sources below. They draw on these sources for ideas:

| Skill | Draws on | License of the source |
| --- | --- | --- |
| `design-direction` | "frontend-design" from [anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/frontend-design): plan before building, check the plan against generic defaults, then critique the result. | Apache License 2.0 |
| `design-system` | "design-system-starter" as listed on [aitmpl.com](https://www.aitmpl.com/component/skills/development/design-system-starter): token layers, component architecture, states. | MIT |
| `accessibility` | [WCAG 2.2](https://www.w3.org/TR/WCAG22/) (W3C). Success criteria are cited by number. | W3C standard |
| `ux-writing` | "avoid-ai-writing" by Conor Bronsdon ([conorbronsdon/avoid-ai-writing](https://github.com/conorbronsdon/avoid-ai-writing)): patterns that make text sound machine-written. Also the general advice of Strunk's *The Elements of Style* (1918, public domain). | MIT / public domain |

The figma-bridge specifics (tool names, the order of calls, the `execute_code` recipes and their pitfalls) come from building and testing this bridge against Figma.
